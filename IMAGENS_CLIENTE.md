# Mapa de Imagens — Casa de Nabais

**Para o cliente:** Este documento lista todas as imagens necessárias para o website.  
Entrega cada imagem com o nome exacto indicado, dentro da pasta correcta.  
Ao substituir uma imagem, basta colocar o ficheiro no lugar certo — não é preciso alterar código.

---

## Formato e Qualidade

| | |
|---|---|
| **Formato** | `.webp` (converte JPG/PNG para WebP antes de entregar) |
| **Qualidade** | 85–90% |
| **Horizontal (landscape)** | Mínimo 1920 × 1080 px · proporção ≥ 16:9 |
| **Vertical (portrait)** | Mínimo 900 × 1200 px · proporção 4:5 |
| **Quadrado/Pessoa** | Mínimo 800 × 1000 px · proporção 3:4 |
